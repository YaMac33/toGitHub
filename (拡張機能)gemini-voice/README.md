# Gemini ボイス

Webページの**読み上げ**と、話した内容を文字にする**音声入力**を、1つにまとめた拡張機能です。
Chrome と Edge で、同じフォルダをそのまま使えます。

## インストール（開発者モード）

1. zipを展開する
2. Chrome は `chrome://extensions`、Edge は `edge://extensions` を開く
3. 「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」（Edge は「展開して読み込み」）で、展開したフォルダを選ぶ
5. 設定画面が開くので、Gemini APIキーを貼り付けて「接続テスト」を押す
6. 音声入力を使う場合は、設定画面の「マイクを許可する」を押す（最初の1回だけ）

※ 以前の「Gemini 音読」「Gemini 音声入力」を入れている場合は、ショートカットが重なるので削除してください。

## 使い方

### 読み上げ
- ツールバーのアイコン →「このページを読み上げ」、または `Alt+Shift+R`
- 文字を選択していれば、その部分だけ読みます。右クリックメニューからも使えます
- 読み上げ中は、ページの右下に操作パネルが出ます（一時停止・前後の段落・停止・速さ）

**声は2種類から選べます**
- **Geminiの声**：自然で高品質。APIキーとネット接続が必要
- **端末の声**：無料・APIキー不要。パソコンに入っている声を使うので、オフラインでも使えます（ネット接続が必要な声もあるので、設定画面の表示で確認してください）

### 音声入力
1. 文字を入れたい入力欄をクリックする
2. `Alt+Shift+V`（またはアイコン →「音声入力」、入力欄の右クリック →「ここに音声入力」）
3. 話し終わったら、もう一度 `Alt+Shift+V`、またはパネルの「停止して文字にする」
4. カーソルの位置に文字が入ります。クリップボードにもコピーされます

- 録音中は `Esc` でキャンセルできます
- 「仕上げ方」で、話した通り／読みやすく整える／箇条書き／です・ます調の文章を選べます
- 「よく使う言葉」に人名・地名・専門用語を書いておくと、その表記で書きます
- 結果は直近20件までこのブラウザに保存され、ポップアップからコピーできます

## 注意

- Geminiの声と音声入力では、読み上げる文章と録音した音声がGoogleのAPIへ送られます。機密情報や個人情報を含む内容では使わないでください
- LGWAN側の端末など、インターネットにつながらない環境では、Geminiの声と音声入力は使えません（端末の声での読み上げだけ使えます）
- 使った分だけGemini APIの利用量がかかります。読み上げは1回3万文字まで、録音は1回20分までです
- 無料枠では、混み合いの制限にかかることがあります。そのときは自動で待ってからやり直します
- ブラウザの設定画面やストアのページ、別サイトのiframeの中、Googleドキュメントなどの独自エディタには文字を入れられません。その場合はコピーだけ行い、パネルに結果を表示します
- ショートカットが「未設定」になっている場合は、設定画面の「ショートカットを変更」から割り当ててください

## ファイル構成

| ファイル | 役割 |
|---|---|
| manifest.json | 拡張機能の定義 |
| background.js | 司令塔（開始・停止、状態の管理、端末の声での読み上げ、文字の挿入） |
| offscreen.js / .html | 裏側のページ（Gemini APIの呼び出し、音声の再生、録音） |
| content.js | ページ側（本文の取り出し、入力欄への挿入、右下の操作パネル） |
| panel.js | 操作パネルの描画（ポップアップとページ側で共通） |
| lib.js | 共通の設定と処理（文章の分割、指示文、APIの応答の読み取りなど） |
| popup.* / options.* / mic.* | ポップアップ、設定画面、マイク許可の画面 |
